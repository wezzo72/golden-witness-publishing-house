How the catalogue was made

On 19 October 2026 the Git tree API listed twelve repositories. 50,939 blobs were counted. 8,113 public publication files of at least one kilobyte, excluding dependency folders and pointer-sized Git LFS stubs, are in the free library. None of the source repositories was edited.

barrandodger.com returned HTTP 404. The GitHub Pages copies of the older sites answered. The Chosen Witness answered. Simplebooklet was not scraped. Full texts were not read. SHA-256 was computed for these inventory files, not for every source blob. Git blob SHA is the duplicate key.

Working papers: readiness, missing materials, file manifest, JSON export.
